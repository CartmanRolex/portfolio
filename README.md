# Gal Pascual — Portfolio

Minimal English portfolio with Projects and CV pages sharing `style.css` and a stable two-tab navigation.

The `cv/index.html` page is generated from the private CV repository. Edit `main.tex` there and push to refresh the public HTML automatically. Private contact fields, portrait and PDF are excluded from the site output. The private PDF remains in the private CV repository only.

Static HTML and CSS, no dependencies.
